# 真机验收

不使用模拟器、虚拟相机或模拟设备。下列硬件相关项目必须在目标系统与实际 USB 相机上执行，不可用单元测试替代。

- [ ] Windows + UVC USB：识别设备、分辨率、预览、PNG 拍照。
- [ ] macOS + UVC USB：权限首次请求、拒绝后的指引、允许后的预览和拍照。
- [ ] 视频模式：实际 USB 摄像头录制 MP4 / H.264，计时、Space 开始/停止、持续预览、停止后播放检查时长与画面。
- [ ] 录制时锁定模式、批次与相机配置；关闭窗口先完成视频保存，重连/拔插/编码或磁盘错误不产生假成功。
- [ ] 视频实验信息、数据集 ZIP 导入导出、工作区备份与回收站恢复一致。
- [ ] 素材库混排真实图片与视频；类型、批次、搜索及时间筛选一致，当前筛选结果导出内容相符，双击视频可正常播放，混合删除后可恢复。
- [ ] macOS 左上角原生红黄绿按钮：关闭、最小化、全屏和恢复，拖动及缩放正常。
- [ ] 照片和视频保存成功后播放完成音效；关闭开关后静音、重启保留设置，试听和系统音量正常。
- [ ] 参数仅按能力开放；检查曝光、白平衡和对焦的设备实际效果。
- [ ] 占用摄像头、拔插、重连、长期无帧时提示明确，不保存旧画面。
- [ ] 多矩形热区输出像素准确，分辨率变化后模板失效，无静默缩放。
- [ ] 连拍 / 倒计时 / 定时采集、低速磁盘不无限积压。
- [ ] 磁盘不足、写入失败、异常退出后重启，不出现假成功。
- [ ] 万张真实实验图片：缩略图滚动、批次搜索、后台导出期间窗口可操作。
- [ ] 中文路径、同名导入、超长名称、最小窗口、高分屏、键盘多选与焦点。
- [ ] ZIP 导出再导入数量、校验值、元数据和所有处理版本一致。
- [ ] 工作区备份包含回收站，可恢复到新目录；当前目录不被覆盖。
- [ ] 两平台安装包真机启动，macOS 签名、公证、相机 entitlement 与权限说明。
